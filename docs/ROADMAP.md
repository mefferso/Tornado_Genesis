# Roadmap

| Phase | Status |
| --- | --- |
| 1 · 3D environment | Volumetric storm, flat reference terrain, rain shafts, 12 camera presets, orbit/fly, compass, graphics settings and Pages workflow |
| 2 · Lifecycle | Continuous 90-minute case, 12 narrative stages, playback/seek/step/loop and separate circulation, condensation and dust |
| 3 · Meteorological layers | Shared analytic wind, flow markers and streamlines, horizontal vectors, scalar slices with units, basic probe and depth clipping |
| 4 · Cross sections | Add arbitrary vertical and rotated sections, time-height plots, vertical exaggeration and annotated analysis plots |
| 5 · Lagrangian analysis | Add parcel release, time-dependent integration and histories. Distinguish pathlines from streamlines and vortex lines. |
| 6 · Radar | Add beam sampling and radial velocity. Implement reflectivity from hydrometeor output when available. |
| 7 · Comparisons | Add hodograph and consistently derived helicity and shear, followed by independently labeled conceptual or numerical cases. |
| 8 · Numerical data | Confirm redistribution and inspect dataset headers. Prototype progressive ingestion of a small annotated subset with nested resolution and bounded memory. |

Prioritize time-dependent parcels and a rotated vertical section for tracing interactions between near-ground vorticity, low-level convergence and the parent updraft. Pressure, buoyancy and vorticity source budgets require a suitable numerical dataset or a separately validated dynamical calculation.
